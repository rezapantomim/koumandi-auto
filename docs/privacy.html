Privacy Policy — KOUMANDI Uploader

KOUMANDI Uploader is used only by the owner of the YouTube channel @koumandiapp to manage that channel.

Data accessed: through the YouTube Data API it uploads videos, sets thumbnails, adds videos to playlists and posts comments on the owner's own channel. It reads only the owner's channel information needed for that.

Storage: the OAuth refresh token is stored as an encrypted secret in the owner's GitHub repository. No other personal data is collected or stored, and nothing is shared with or sold to third parties.

Other users: the tool does not access or collect data of any other YouTube user.

Revoking access: the owner can revoke access at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Last updated: 27 November 2026.
